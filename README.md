# README

象棋辅助是一款开源的 Android 中国象棋学习与分析工具，提供本地对弈、棋谱、屏幕棋盘识别、悬浮窗建议和可选自动落子。

> 本项目仅用于个人学习、技术研究与文化交流。使用屏幕识别、悬浮窗或自动落子功能时，请遵守所在平台规则以及当地法律法规。

## 1.3.3 增量修复与发行

- 当前开发版本：象棋辅助 1.3.3（versionCode 7），目标是修复 Android 16 悬浮面板崩溃并统一模型选择行为；正式附件以 `v1.3.3` GitHub Release 为准。
- 已公开的 1.3.2（versionCode 6）、1.3.1 及更早版本保持不变；历史发行说明仍可分别查看对应文档。
- 当前 APK 的模型用户档位为 `Lite / Low / Medium / High`：`High` 是历史复合高效果档，`Medium` 是原生 YOLO26-S 候选，`Low` 是稳定 V5 Medium，`Lite` 是原始 V5 Lite 最终保底。High 不冒充原生大型，Medium 的真实设备效果仍待验证。
- 模型选择只保存配置，不自动创建或展开悬浮窗，也不热切换当前会话；下一次一键准备或点击开始/继续时才读取并执行兼容性探测。

## 主要特色

- **本地象棋对弈**：内置 Pikafish 与 NNUE，可进行人机对弈和局面分析。
- **棋谱管理**：支持打谱、复盘、变着浏览以及常见棋谱导入导出。
- 在辅助页选择 `Lite / Low / Medium / High` 模型档位，记忆用户选择。无历史选择时默认尝试 High，兼容性失败按 High→Medium→Low→Lite 回退；只按资产、运行时、张量契约和受控推理判断，不按负载强制回退。选择动作只保存配置，不自动展开悬浮窗，下一次准备或开始时应用。
- **模型效果与边界**：每个模型文件不得超过200,000,000 bytes；High 当前使用历史复合资源且不称原生大型；Medium 是原生 YOLO26-S 候选；Low 为稳定 V5 Medium；Lite 为原始 V5 最终保底。后续只寻找已有成品权重并做本地转换，禁止从零训练。
- **棋盘范围框选**：可调整并记忆识别区域，减少棋盘区域之外画面变化的影响。
- **思考设置上限**：可选总思考时间最高120秒，主变候选最多5条；历史配置超限时会被安全夹到新上限。
- **稳定帧判定**：录屏流保持每秒8个样本；只有连续8个样本画面稳定（约0.875秒），才选择其中较清晰的一帧识别；全局看门狗补采不跳过这个稳定门。
- **识图恢复**：持续确认采帧、稳定窗、推理和识别进展；异常棋面拒绝后继续受控识别，避免用未经验证的局面指导自动落子。
- **暂停与关闭**：暂停时停止向应用输出帧并释放帧读取器，尽量保留投影授权和无障碍前台监听；切出触发的临时暂停与手动暂停分别恢复。
- **预选与落子**：预选切换不同棋子时点按其起点，点按间隔随机 1250–2500ms；正式落子起点到终点的既有随机时序独立保持。
- **变招二次点击取消**：用户可随时提前点击“变招”存下下一次我方非默认候选；按钮绿色时再次点击会清除存量并立即恢复白色。实际非默认着法完成核对后也会自动清除存量并恢复白色。
- **悬浮窗执子方**：手动选择和自动检测互斥；自动检测使用屏幕棋盘下半区的帅/将作为阵营锚点。手动和自动模式分别保存颜色选择。
- **双引擎变体**：提供通用 ARMv8 与 ARMv8 dotprod 版本。

## 使用概览

1. 安装与设备匹配的 APK 并打开应用。
2. 使用屏幕辅助时进入“悬浮窗辅助”并完成一键准备。
3. 准备完成后会话保持暂停；打开悬浮窗并点击“开始”才进行识别和计算。
4. 切换到目标象棋应用，等待棋盘稳定后查看建议。
5. 如需自动落子，再开启本应用无障碍服务和自动走子。

## 权限与隐私

- **屏幕录制**：用于本地棋盘识别。
- **悬浮窗**：用于展示棋盘、状态和建议。
- **无障碍服务**：仅用于发送用户选择的坐标手势，不读取控件文字或遍历界面内容。
- **root（可选）**：尝试启用本应用无障碍服务，不是安装和基础识别所必需。
- 识别和引擎计算在设备本地完成，不要求上传棋盘截图。

## 从源码构建

要求 JDK 17、Android SDK 34，并使用 Gradle Wrapper。

```bash
# 通用 ARMv8 Release
./gradlew :app:assembleArmv8-Release

# ARMv8 dotprod Release
./gradlew :app:assembleArmv8-dotprod-Release

# JVM 单元测试
./gradlew :app:testArmv8-DebugUnitTest
```

未提供发布密钥时，本地源码构建使用 Android Debug 签名，仅供测试。正式签名由 `v1.3.3` GitHub Actions 工作流从仓库加密密钥注入；不要将本地调试签名 APK 当作正式附件。公开版 `v1.3.2`、`v1.3.1` 与更早版本保持原样。
