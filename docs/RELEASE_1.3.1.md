# 象棋辅助 1.3.1 发布说明

## 版本信息

- 应用版本：`1.3.1`
- 版本代码：`5`
- 包名：`com.xiangqi.assist`
- 发行标签：`v1.3.1`
- 兼容变体：通用 ARMv8 与 ARMv8 dotprod
- 前一正式版本 `v1.3` 保持不变；本版是可独立回退的增量修复。

## 修复内容

- 落子核对期间，持续采集的样本、稳定窗进展和正在执行的识别任务不再被误判为“识图无进展”；仍保留落子核对的绝对超时保护。
- 落子核对超时后的新棋面必须与落子前局面、预期落子后局面或预期局面后的一步合法对手应手相符；无法解释的观测不会直接成为分析或自动落子的基线。
- 前台应用观察记录无障碍连接、全屏状态、稳定候选与数据不可用原因，便于定位自动暂停和返回恢复的问题。
- 悬浮面板执子方状态按钮会随“检测到红/黑”等文字调整宽度；在悬浮球或面板未显示时切换策略只保存选择，不主动弹出面板。
- 更新棋谱请求补充了服务端请求与门控原因记录，便于区分点击未到达、暂停状态、没有新画面和识别拒绝。

## 发行文件

| 文件 | 适用设备 |
| --- | --- |
| `xiangqi-assist-1.3.1-armv8.apk` | 通用 64 位 ARM Android 设备 |
| `xiangqi-assist-1.3.1-armv8-dotprod.apk` | 支持 ARMv8.2 dotprod 指令的设备 |
| `SHA256SUMS.txt` | 同次发行生成的 APK 校验值 |

正式附件由 `v1.3.1` 标签对应的 GitHub Actions 使用仓库发布密钥构建和签名；本地调试签名构建不属于正式发行文件。

## 验证边界

自动化测试覆盖落子核对重建、前台观察稳定窗口、隐藏/展开面板切换和按钮文本布局。真实设备上的前台切换、通知/权限窗口兼容性、按钮实际显示尺寸，以及用户提供的帅/将错格截图仍需在目标设备复核；未验证的行为不视为真机通过。
