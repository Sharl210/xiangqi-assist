# 悬浮窗辅助功能说明

悬浮窗辅助把“屏幕棋盘识别、Pikafish 分析、走法展示和可选自动落子”组成一条本地运行链路。页面只负责准备环境和启停；详细用法集中在本文与应用内“帮助”页面。

## 运行方式

1. 在首页进入“悬浮窗辅助”。
2. 点击“一键准备”，按系统提示授予悬浮窗、通知和屏幕录制权限。
3. 一键准备只建立环境，完成后仍保持停止，不取帧、不识别、不计算。
4. 点击绿色“一键启动”后才进入运行态；运行时按钮变为红色“一键关闭”。
5. 切换到目标象棋应用，等待画面稳定后查看悬浮窗结果。

一键关闭会停止识别、计算和自动落子，但保留已经取得的录屏环境，之后可再次一键启动。悬浮窗内也保留“开始、继续、暂停”控制。

## 八帧稳定识别

- 录屏流固定每秒取 4 个低频样本，即每 250ms 一个。
- 必须连续 8 个样本画面稳定，约 2 秒，才判定当前棋盘足够稳定。
- 稳定窗口中只选较清晰的一帧送入 YOLO/TensorFlow Lite，模型只推理一次，不进行多次截图投票。
- 动画、拖动或画面变化会使当前窗口重新计数。
- 识别结果还需通过模型置信度、棋盘结构、棋子数量和轮次检查；异常结果会被拒绝，不用历史棋面替换当前棋子类别。

## 辅助页控件

- **悬浮窗权限**：允许在其他应用上方显示棋盘、状态和建议。
- **通知权限**：允许前台录屏服务显示通知。
- **一键准备**：检查权限、可选操作通道和屏幕录制环境，不自动开始。
- **一键启动 / 一键关闭**：显式开始或停止识别、计算和自动落子。
- **屏幕操作通道**：打开系统无障碍设置。自动落子需要该通道，纯识别和建议不需要。
- **root 一键开启通道**：设备有可用 root 时，可尝试把本应用加入已启用无障碍服务列表；会保留用户原有服务。
- **自动走子**：开启后只在轮到我方、建议定着、识别健康和通道可用时派发手势；关闭时只提示。
- **落子方式**：选择点击起点再点击终点，或从起点拖到终点。
- **引擎线程**：自动或 1～8 线程，对下一次搜索生效。
- **悬浮球大小**：范围 70%～150%，默认 90%。程序会把球限制在状态栏、挖孔和导航栏之间的安全区域。

## 悬浮窗菜单

- **开始 / 继续 / 暂停**：控制当前会话。没有显式点击开始时保持停止。
- **模式**：在自动、半自动和手动摆子之间切换。半自动由用户点击“更新棋谱”应用棋面；手动模式不持续截图。
- **自动**：开关自动落子。
- **仿真**：控制随机偏移、随机延迟和候选起点预选。
- **候选数量**：设置同时计算的主变数量。
- **变招**：浏览已计算出的候选，不重启当前搜索。
- **悔棋**：回到上一个已确认局面。
- **更新棋谱**：立刻从屏幕重新读取并应用局面。
- **重置**：清除当前棋面、建议和在途事务，从当前屏幕重建基线。
- **己方红 / 己方黑**：明确指定本次分析方，不根据屏幕上下位置猜测。
- **切换走棋方**：纠正当前轮次。
- **深度 / 总时 / 每候选时间**：短按切换当前档位，长按切换思考方式。
- **Hash**：调整引擎哈希内存。
- **缩小**：把面板缩成悬浮球；单击球恢复面板，拖动球改变位置。
- **关闭**：关闭悬浮窗、录屏和前台服务；再次使用需要重新准备。

## 箭头、状态与悬浮球

- 蓝色箭头表示仍在计算的暂定候选。
- 绿色箭头表示建议已定着或搜索结束。
- 对方回合只展示应对预案，不把我方应手误画成对方当前着法。
- 识别中断或不稳定时隐藏旧建议，避免用过期结果继续落子。
- 悬浮球显示胜率和当前阶段。拖动结束后位置立即保存；如果旧位置位于屏外或系统栏中，下次显示会自动夹回可见区域。

## 自动落子边界

自动落子使用本应用的无障碍服务发送坐标手势，不读取控件文字、不遍历界面节点。每次正式落子前会检查：

- 服务处于用户显式启动状态；
- 当前模式允许自动操作；
- 轮到用户指定的一方；
- 建议对应当前棋面且已经定着；
- 识别画面新鲜、稳定且结构有效；
- 屏幕操作通道已连接；
- 起点确实是己方棋子；
- 没有另一个落子或核对事务正在执行。

落子后会等待新画面确认是否生效；失败时按有限次数恢复，避免持续点击。离开棋盘应用时，前台切换保护会暂停识别和手势；返回原棋盘后按保存的运行意图重新建立基线。回到应用控制页时仍可用红色“一键关闭”取消该运行意图。

## 权限与隐私

- **屏幕录制**：仅用于设备本地棋盘识别。
- **悬浮窗**：用于显示棋盘、状态和建议。
- **通知**：用于 Android 前台录屏服务。
- **无障碍服务**：仅在自动落子时发送坐标手势。
- **root**：可选，只用于尝试启用或恢复本应用无障碍服务。

识别和引擎计算均在设备本地完成，不要求上传棋盘截图。

## 已知验证边界

- 生产常量、稳定窗口测试、默认停止策略和悬浮球安全区几何可在本地自动验证。
- 当前构建环境没有连接真机；不同 ROM 的录屏授权、透明系统栏、无障碍手势、悬浮球层级以及八帧窗口的实际体感仍需用户真机验证。
- 不确定设备是否支持 dotprod 时，应使用普通 ARMv8 APK。

## 使用边界

本应用仅供个人学习、技术研究与文化交流。屏幕识别、悬浮窗建议和自动落子均由用户主动启用；使用时请遵守当地法律法规、软件许可和所在平台规则。
