# 悬浮窗辅助功能说明

悬浮窗辅助把“屏幕棋盘识别、Pikafish 分析、走法展示和可选自动落子”组成一条本地运行链路。页面只负责准备环境和启停；详细用法集中在本文与应用内“帮助”页面。

## 运行方式

1. 在首页进入“悬浮窗辅助”。
2. 点击“一键准备”，按系统提示授予悬浮窗、通知和屏幕录制权限。
3. 准备成功后会话保持暂停，不取帧、不识别、不计算；辅助页主按钮显示红色“一键关闭”。
4. 打开悬浮窗并点“开始”后才进入运行态；暂停会停止帧输出，但尽量保留投影授权和无障碍前台监听。
5. 切换到目标象棋应用，等待画面稳定后查看悬浮窗结果。

一键关闭会结束辅助会话、释放投影与悬浮窗并撤销通知，同时尝试关闭本应用无障碍服务；若系统未确认停用，会提示到设置中完成。暂停时不会继续把帧交给应用处理，切回原棋盘后，若是因切出触发的临时暂停会按原运行状态自动恢复；若是手动暂停则仍保持暂停，需在悬浮窗点“继续”。Surface无法重接或系统结束投影时才重新授权。

## 识别模型档位

辅助页可选择 YOLO 识别模型，设置会记住上次选择。默认新安装首选**大型**，但大型模型必须先通过设备兼容性检查：资产能否读取、TFLite Interpreter 能否创建、张量能否分配、输入输出形状是否匹配，以及一次受控推理能否执行。

- **大型**：真实的双模型集成工件，大小约 54.26 MiB；同时执行当前中型模型与 universal/旋转鲁棒模型，并逐检测锚点选择更高置信结果，目标是提高复杂皮肤、旋转和装饰差异下的鲁棒性，推理时间与功耗通常接近单模型的两倍。
- **中型**：当前内置的平衡档，在识别能力、速度和资源占用之间折中。
- **Lite**：资源和兼容性优先，模型更小，通常更快、更省内存；复杂皮肤下的识别能力需要以实际画面为准。

如果目标档位不兼容，程序会说明失败阶段和原因，并按**大型→中型→Lite**顺序自动回退；回退成功后辅助页会同步显示实际使用档位。CPU负载、温度、功耗和当前速度只作为选择时的温馨提示，不会因为设备当前较忙就强制回退。三档都无法加载时会提示“设备无法加载任何象棋识别模型”，不会假装进入正常识别。

当前评估文档见 `docs/YOLO模型档位评估.md`。Large 的真实模型文件、识别质量、速度、功耗和温升必须以同一设备、同一输入帧集的测量结果为准。


- 录屏流固定每秒取 8 个低频样本，即每 125ms 一个。
- 必须连续 8 个样本画面稳定，约 0.875 秒，才判定当前棋盘足够稳定。
- 稳定窗口中只选较清晰的一帧送入 YOLO/TensorFlow Lite，模型对这张关键帧推理一次。
- 动画、拖动或画面变化时，窗口每次只前移一个125ms样本；稳定失败后不会重新等待整组样本。
- 全局识图看门狗在约500ms没有新的样本消费时只做一次非破坏性补采，不会跳过8样本稳定门；等待对方阶段补采阈值为250ms，其它识图阶段为500ms。
- 识别结果还需通过模型置信度、棋盘结构、棋子数量和轮次检查；异常结果会被拒绝并立即请求受控重识别，不用历史棋面替换当前棋子类别。
- **完整盘面变化**：缺子保护只拦截证据充分的残缺子集；完整的新盘面交给连续帧跟踪确认，不会因棋子位置发生多格变化而无限重试。
- **落子核对超时**：保留上一张已确认棋面作临时显示，停止沿用旧建议，等首个新稳定画面确认后再建立基线，避免棋盘突然清空。

## 辅助页控件

- **悬浮窗权限**：允许在其他应用上方显示棋盘、状态和建议。
- **通知权限**：允许前台录屏服务显示通知。
- **一键准备**：检查权限并建立录屏会话，完成后会话保持暂停；辅助页主按钮随即显示红色“一键关闭”。
- **开始 / 继续 / 暂停**：在悬浮窗中显式控制识别运行；首次准备不会自动开始。暂停时停止向应用输出帧、关闭帧读取器，尽量保留投影授权与无障碍前台监听；若系统结束授权或设备无法重接Surface，再重新授权。
- **屏幕操作通道**：打开系统无障碍设置。自动落子需要该通道，纯识别和建议不需要。
- **root 一键开启通道**：设备有可用 root 时，可尝试把本应用加入已启用无障碍服务列表；会保留用户原有服务。
- **自动走子**：开启后只在轮到我方、建议定着、识别健康和通道可用时派发手势；关闭时只提示。
- **落子方式**：选择点击起点再点击终点，或从起点拖到终点。
- **引擎线程**：自动或 1～8 线程，对下一次搜索生效。
- **悬浮球大小**：范围 70%～150%，默认 90%。程序会把球限制在状态栏、挖孔和导航栏之间的安全区域。

## 悬浮窗菜单

- **开始 / 继续 / 暂停**：控制当前会话。未开始时不取帧、不识别、不计算；暂停会断开屏幕输出并释放帧读取器，但保留授权会话及无障碍前台监听。
- **仿真**：控制随机落点偏移和候选起点预选。切换到另一枚棋子时，先点按它的起点使其成为选中目标；与上一次预选起点点按之间每次随机间隔750–1250ms（含端点）。这不改变正式落子起点到终点之间、独立按220ms基准的30%～100%随机等待。
- **候选数量**：设置同时计算的主变数量。
- **预存与执行**：用户可在对方回合、引擎计算中或局面快速变化时点击“变招”，存下下一次我方落子使用第二候选/第一个非默认候选的意图；存量期间“变招”文字为绿色，候选未到达时等待，不回落默认着法。绿色预存状态再次点击会取消变招并立即恢复白色；实际非默认落子完成核对后，存量取消，按钮文字也恢复白色。
- **更新棋谱**：立刻从屏幕重新读取并应用局面。
- **框选棋盘范围**：拖动四角设置识别区域；之后变化监听、稳定帧和棋盘识别都限制在框内，范围会被记住。
- **重置**：清除当前棋面、建议和在途事务，从当前屏幕重建基线。
- **己方红 / 己方黑**：明确指定本次分析方，不根据屏幕上下位置猜测。
- **切换走棋方**：纠正当前轮次。
- **深度 / 总时 / 每候选时间**：短按切换当前档位，长按切换思考方式。
- **Hash**：调整引擎哈希内存。
- **缩小**：把面板缩成悬浮球；单击球恢复面板，拖动球改变位置。
- **一键关闭**：关闭整个辅助会话，释放屏幕投影与悬浮窗，并关闭本应用无障碍服务；再次使用需要重新准备。

## 箭头、状态与悬浮球

- 蓝色箭头表示仍在计算的暂定候选。
- 绿色箭头表示建议已定着或搜索结束。
- 对方回合只展示应对预案，不把我方应手误画成对方当前着法。
- 识别中断或不稳定时隐藏旧建议，避免用过期结果继续落子。
- 悬浮球显示胜率和当前阶段。收缩后通知栏显示“悬浮球已显示”，展开面板后同步恢复面板状态文案；拖动结束后位置立即保存；如果旧位置位于屏外或系统栏中，下次显示会自动夹回可见区域。

## 自动落子边界

自动落子使用本应用的无障碍服务发送坐标手势，不读取控件文字、不遍历界面节点。每次正式落子前会检查：

- 服务处于用户显式启动状态；
- 当前模式允许自动操作；
- 轮到用户指定的一方；
- 建议对应当前棋面且已经定着；
- 识别画面新鲜、稳定且结构有效；
- 屏幕操作通道已连接；
- 起点确实是己方棋子；
- 没有另一个落子或核对事务正在执行。

离开棋盘应用时若系统触发临时保护暂停，回到原棋盘后会在授权仍有效时自动恢复此前运行状态，并从新帧建立基线。手动点击“暂停”则不会因切回棋盘而自动开始，须由用户在悬浮窗点“继续”。Surface无法重接或系统终止投影时，才请求重新授权。

## 权限与隐私

- **屏幕录制**：仅用于设备本地棋盘识别。
- **悬浮窗**：用于显示棋盘、状态和建议。
- **通知**：用于 Android 前台录屏服务。
- **无障碍服务**：仅在自动落子时发送坐标手势。
- **root**：可选，只用于尝试启用或恢复本应用无障碍服务。

识别和引擎计算均在设备本地完成，不要求上传棋盘截图。

## 已知验证边界

- 生产常量、稳定窗口测试、默认停止策略和悬浮球安全区几何可在本地自动验证。
- 当前构建环境没有连接真机；不同 ROM 的录屏授权、透明系统栏、无障碍手势、悬浮球层级以及八样本稳定窗口的实际体感仍需用户真机验证。
- 不确定设备是否支持 dotprod 时，应使用普通 ARMv8 APK。

## 使用边界

本应用仅供个人学习、技术研究与文化交流。屏幕识别、悬浮窗建议和自动落子均由用户主动启用；使用时请遵守当地法律法规、软件许可和所在平台规则。
