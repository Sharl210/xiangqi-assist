# 象棋辅助 1.3.2 发布说明

## 版本信息

- 应用版本：`1.3.2`
- 版本代码：`6`
- 包名：`com.xiangqi.assist`
- 发行标签：`v1.3.2`
- 兼容变体：通用 ARMv8 与 ARMv8 dotprod
- `v1.3` 与 `v1.3.1` 正式发行保持不变；本版为后续增量修复。

## 本版内容

- 修复前台应用观察链：无障碍服务在必要范围内读取活动窗口包名和边界，观察数据暂时不可用时安全暂停识别，连续稳定确认切换后按原运行/暂停状态处理返回。
- 增加同一棋盘格出现不同类别检测框时的安全拒绝，避免仅按置信度强行提交错误棋子类别。
- 时间模式上限调整为120秒，候选数量上限调整为5；历史超限配置读取时自动夹到新上限。
- 预选棋子切换点按间隔调整为每次随机1250–2500毫秒；全局采样补采与管线看门狗按计划缩短，同时保留连续8个稳定样本门。
- 悬浮面板按钮栏记忆用户最后到达的按钮锚点，面板展开、缩小或行数改变后恢复到同一按钮附近。
- 识别模型设置增加“超大型”目标档位；当前中型档已接入原生 YOLO26-S 中国象棋15类候选及独立 `[1,19,8400]` raw 输出适配器，效果和真机性能仍待验证；大型与超大型没有合格原生工件时按真实兼容性回退，不把旧集成冒充原生大型。单模型文件上限为200,000,000 bytes，负载和温度不作为强制回退条件。
- 帮助页同步说明模型档位、前台暂停、识别安全门、参数上限和预选间隔。
