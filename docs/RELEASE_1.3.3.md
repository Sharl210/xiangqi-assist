# 象棋辅助 1.3.3 发布说明

## 版本信息

- 应用版本：`1.3.3`
- 版本代码：`7`
- 包名：`com.xiangqi.assist`
- 发行标签：`v1.3.3`
- 兼容变体：通用 ARMv8 与 ARMv8 dotprod
- `v1.3.2` 及更早正式发行保持不变；本版是 Android 16 崩溃和模型配置行为的增量修复。

## 本版内容

- 修复悬浮面板按钮行异步滚动锚点恢复：延迟任务绑定重建代号，访问子项前检查父容器、行范围和子项范围，避免 Android 16/特定 ROM 上调用空对象 `View.getLeft()`。
- 增加按钮锚点无效索引回归测试；源码与 JVM 定向测试通过后仍需 realme RMX5200 / Android 16 真机复测。
- 模型选择统一为 `Lite / Low / Medium / High` 四个效果语义档位，不再向用户展示“超大型”等不存在的选项。
- `High` 明确标注为历史复合资源，不冒充原生大型；`Medium` 为原生 YOLO26-S 候选；`Low` 为稳定 V5 Medium；`Lite` 为原始 V5 Lite 最终保底。
- 模型选择动作只保存配置，不创建或展开悬浮窗，不启动识别，也不热切换当前会话；下一次一键准备或点击开始/继续时才执行兼容性探测。
- 旧模型选择值自动迁移到新的效果语义档位，帮助页、设置页和模型评估文档同步更新。

## 验证边界

- **验证边界**：本机已完成 Kotlin 编译和35项定向测试；全量 JVM 测试424项中416项通过，8项因 Linux/aarch64 缺少 Robolectric native 图形库失败。远程 ARMv8 与 dotprod Release、签名、哈希、帮助资源回读及 realme RMX5200 Android 16 真机复测仍待完成。
