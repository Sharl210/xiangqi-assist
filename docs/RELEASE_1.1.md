# 象棋辅助 1.1 发布说明

## 版本重点

象棋辅助 1.1 提高了屏幕棋盘稳定判定，并重新整理应用主页和悬浮窗辅助控制页。准备环境与开始运行现在完全分开，悬浮球也增加了可见区域保护。

## 本版更新

- 录屏仍按每秒 4 个样本检查；连续 8 个样本稳定约 2 秒后，只选择其中较清晰的一帧识别一次。窗口采用滑动推进，失败后每次只前移一个250ms样本，不整窗清空。
- “一键准备”只完成权限、操作通道和录屏环境，不再隐含开始操作。
- 新增绿色“一键启动”和红色“一键关闭”；未点击启动时，不取帧、不识别、不计算、不自动落子。
- 一键关闭后保留已经准备的录屏环境，方便稍后重新启动。
- 修复悬浮窗缩成悬浮球后可能位于屏外或系统栏内、导致找不到的问题。
- 悬浮球默认尺寸增大，并限制在状态栏、挖孔和导航栏之间的安全区域。
- 首页入口由“连线”更名为“悬浮窗辅助”。
- 更换旧竹子背景，主页和辅助页改为与新 Logo 一致的深蓝、金色和朱红主题。
- 状态栏与导航栏采用透明沉浸式显示，内容自动避开系统安全区域。
- 精简辅助页说明文字，把权限、控制项和悬浮窗全部菜单用法集中到应用“帮助”。
- 清理对弈与打谱状态回调中的两个未实现空分支，空状态不再触发异常。
- README、功能说明、架构记录和应用内帮助同步更新。

## 主要功能

- 本地 Pikafish 与 NNUE 人机对弈、局面分析。
- 棋谱打谱、导入、导出、复盘和变着浏览。
- YOLO 与 TensorFlow Lite 本地屏幕棋盘识别。
- 八帧画面稳定、模型置信度和棋盘结构多层检查；低置信或尺寸边缘棋子不再被旧的过严阈值静默丢弃。
- 已有可靠盘面出现明显残缺子集时拒绝当前关键帧，不用旧棋面补写缺失棋子；合法的一步移动（含吃子）仍可通过。
- 前台保护只采用真实全屏 application window；通知、输入法、权限弹窗等瞬时系统层不触发暂停，切出后返回原棋盘应用才恢复切出前的运行意图。
- 首次工作模式默认为自动并持久化；悬浮窗运行按钮只显示“开始”“继续”“暂停”。
- 悬浮窗迷你棋盘、候选走法、评分、主变和红黑方选择。
- 指导、半自动、手动摆子与自动走子模式。
- 深度、总时间、每候选时间、候选数量、Hash 和线程设置。
- 可选无障碍点击或拖动落子；有 root 时可尝试自动启用操作通道。
- 识别和计算均在设备本地完成。

## APK 选择

- **象棋辅助_1.1_通用ARMv8版.apk**：适合绝大多数 64 位 ARM Android 设备，兼容性优先。
- **象棋辅助_1.1_ARMv8点积优化版.apk**：适合支持 ARMv8.2 dotprod 指令的较新设备。

不确定设备是否支持 dotprod 时，请下载通用 ARMv8 版。

## 文件校验

GitHub Release 附带 `SHA256SUMS.txt`，其中记录该 Release 实际下载文件的 SHA-256。两个 APK 均需满足：应用名“象棋辅助”、包名 `com.xiangqi.assist`、版本 `1.1`、版本代码 `2`，APK v2 签名验证通过。

## 验证情况

- 八帧稳定窗口、默认停止/显式启停和悬浮球安全区的定向 JVM 测试全部通过。
- 定向回归测试全部通过，覆盖滑动窗口、前台切换、默认模式、缺子保护、YOLO 后处理、落子回执和核心棋面逻辑。
- 完整 JVM 单元测试共 346 项：338 项通过；其余 8 项均因当前 ARM Linux 主机缺少 Robolectric 所需的 `conscrypt_openjdk_jni-linux-aarch_64` 原生库而失败，失败集中在 Activity/Service 启动和绘制测试，并非新增逻辑测试失败或 APK 构建失败。
- 两个 Release 变体均完成干净构建，构建过程中的 `lintVital` 检查通过。
- 当前工作区未提供私有发布密钥，因此本地复核用 APK 使用 Android debug keystore；GitHub 标签工作流在配置发布密钥 Secret 时才生成正式发布签名资产。
- 完整 Lint 任务受 `filepicker` 测试依赖 `junit:4.12` 无本地缓存且外网超时阻塞；没有把该环境失败记为通过。
- 当前环境没有连接真机，也没有可执行的 Android 模拟器；不同 ROM 上的沉浸式系统栏、屏幕录制、无障碍窗口层级、自动手势、模型实际召回率、悬浮球层级和八帧等待体感仍需用户真机验证。
