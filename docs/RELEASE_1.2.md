# 象棋辅助 1.2 发布说明

## 版本信息

- 应用版本：`1.2`
- 版本代码：`3`
- 包名：`com.xiangqi.assist`
- 正式发布标签：`v1.2`
- 发布变体：通用 ARMv8 与 ARMv8 dotprod

1.2是1.1的后续版本，versionName为`1.2`、versionCode为`3`。正式发行资产由推送`v1.2`标签触发的GitHub Actions工作流使用仓库加密密钥构建、签名并上传；1.1的历史发布说明和归档保留在`docs/RELEASE_1.1.md`及`release/1.1/`，本文件记录1.2的正式发行内容与本地验证边界。

## 主要改进

- 增加棋盘识别范围框选，支持拖动边角和记忆范围；配置后，画面变化跟踪、稳定帧处理和棋盘识别使用该区域。
- 缩短并统一识图看门狗：等待对方阶段补采阈值为250ms，其它识图阶段为500ms；全局约500ms无新样本消费时只做非破坏性补采，仍必须满足连续8个稳定样本；相关识图与落子核对硬超时按既有值减半。
- 非法或结构异常棋面会拒绝当前帧并立即请求受控重识别，不用旧棋面冒充当前证据。
- 预选时保存棋面与已计算的落子坐标；满足棋面、分析会话、手势完成及无障碍实例一致条件时，正式自动落子复用快照；落子后仍核对新画面。
- “变招”改为可提前存储的下一次我方落子意图：用户可在对方回合、计算中或待落子变化很快时点击，存量期间按钮文字保持绿色；轮到我方并产生候选后自动/手动选择第二候选或第一个非默认候选；候选暂缺时等待，不回落默认着法；绿色预存状态再次点击会取消变招并恢复白色；完成实际非默认落子核对后清除存量，按钮文字也恢复白色，且不启动新搜索。
- 调整首页“悬浮窗辅助”与“对弈”的顺序和样式，并对调悬浮窗内“仿真”与“重置”的位置。
- 合并“一键准备/一键关闭”状态：准备后会话保持暂停，按钮显示红色“一键关闭”；关闭时结束会话、撤销通知并尝试停用本应用无障碍服务。
- 通知栏随面板/悬浮球状态同步：收缩后显示悬浮球已显示，展开后恢复面板状态，不保留过期的“已缩成悬浮球”文案。
- 暂停时停止向应用输出屏幕帧、释放帧读取器，尽量保留投影授权和无障碍前台监听。切出触发的临时暂停会在原棋盘返回时恢复；手动暂停仍保持暂停。若系统终止投影或设备无法重接Surface，才需重新授权。
- 预选从一枚棋子切换到另一枚棋子的起点选中点按间隔，每次随机750–1250ms（含端点）；正式落子的起点到终点随机间隔保持原策略，不受影响。
