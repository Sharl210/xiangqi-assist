象棋辅助使用帮助

本地对弈、棋谱复盘与悬浮窗识别辅助的完整使用说明。

对弈与棋谱

  • 对弈：使用本地 Pikafish 引擎进行人机对弈，可调整执方、深度或时间、Hash、线程和开局库。
  • 打谱与复盘：浏览着法树、前后移动、导入或导出棋谱，并可从指定局面继续对弈。
  • 普通 ARMv8 与 dotprod 版功能一致；dotprod 版适合支持相应指令集的较新设备。

悬浮窗辅助

首次准备与启停

  1. 点击一键准备，依次完成悬浮窗、通知和系统录屏授权。
  2. 准备只建立运行环境，不会开始识别、计算或自动落子；初始状态始终为停止。
  3. 准备成功后，一键准备已变为红色一键关闭，用于结束整个会话；识别仍保持暂停，须在悬浮窗点开始才启动。
  4. 切换到目标棋盘后，画面按每秒 8 个样本检查；连续 8 个样本稳定（约 0.875 秒）后，才选一帧识别并计算。全局识图看门狗在约500ms没有新的样本消费时只做非破坏性补采；等待对方阶段阈值为250ms，其它识图阶段为500ms。

辅助页控件

  • 悬浮窗权限 / 通知权限：单独补齐对应系统权限。
  • 一键准备：检查权限、操作通道和录屏环境；准备后仍处于暂停，需在悬浮窗内点击开始。
  • 一键关闭：关闭整个辅助会话，停止识别与手势，释放屏幕投影和悬浮窗，并关闭本应用无障碍服务；下次使用需重新准备。
  • 屏幕操作通道：打开系统无障碍设置。它只在自动落子时发送坐标手势。
  • root 一键开启通道：有可用 root 时尝试自动启用本应用的无障碍服务；没有 root 可忽略。
  • 自动走子：开启后，满足轮次、建议定着、识别健康和通道可用等条件时执行着法；关闭时只显示建议。
  • 落子方式：在“点击起点再点终点”和“从起点拖到终点”之间切换。
  • 引擎线程：在自动和 1～8 线程之间切换，对下一次搜索生效。
  • 悬浮球大小：调整球体尺寸；球始终会被限制在屏幕安全区域内。

识别模型档位

  • 大型：默认首选，是真实的双模型集成工件，大小约 54.26 MiB；同时执行当前中型模型与 universal/旋转鲁棒模型，并逐检测锚点选择更高置信结果，目标是提高复杂皮肤、旋转和装饰差异下的鲁棒性，推理时间与功耗通常接近单模型的两倍。
  • 中型：当前内置的平衡档，在识别能力、速度和资源占用之间折中。
  • Lite：资源和兼容性优先，模型更小，通常更快、更省内存；复杂皮肤效果以实际画面为准。
  • 选择会被记住。大型→中型→Lite 的回退只检查模型能否读取、创建 Interpreter、分配张量、匹配输入输出形状并执行一次受控推理；负载、温度、功耗和当前速度只作提示，不会强制回退。
  • 如果目标档位不兼容，程序会说明原因并同步显示实际档位；三档都无法加载时会明确提示，不会假装进入正常识别。Large 的真实能力、速度、功耗和温升以同一设备实测为准。

模型档位评估：docs/YOLO模型档位评估.md。

悬浮窗菜单

  • 开始 / 继续 / 暂停：直接控制当前悬浮会话。未点击开始时保持停止，不取帧、不识别、不计算；暂停会断开屏幕输出、释放帧读取器，但尽量保留授权会话和无障碍前台监听。因切出触发的临时暂停在回到原棋盘后恢复；手动暂停仍须点继续。
  • 模式：在自动、半自动和手动摆子间切换。半自动由“更新棋谱”确认棋面；手动模式不持续截图。
  • 自动：切换自动落子；仿真：控制落点偏移和候选预选。切换到另一枚棋子时，先点按其起点作为选中目标；预选起点之间每次随机间隔750–1250ms（含端点）。正式点击式落子的起点到终点间隔仍独立按220ms基准的30%～100%逐手随机。
  • 候选数量：设置同时计算的主变数量。
  • 变招预存：可在对方回合、计算中或阶段变化很快时提前点击，保存“下一次我方实际落子使用非默认着法”的意图；不要求当前处于待落子。
  • 变招执行：真正轮到我方并产生候选后，自动或手动落子选择第二候选/第一个非默认候选。存量期间按钮文字保持绿色；候选暂未到达时继续等待，不回落默认着法；绿色预存状态再次点击会取消变招并立即恢复白色；实际非默认着法完成核对后，存量取消，按钮文字也恢复白色，且不启动新搜索。
  • 悔棋：回到上一个已确认局面；更新棋谱：立即从屏幕重新读取并应用棋面；框选棋盘范围：拖动四角设置识别区域，之后只在该区域监听画面变化和识别，范围会被记住。
  • 重置：清除当前棋面、建议与事务，重新建立识别基线。
  • 己方红 / 己方黑：指定分析方；切换走棋方：纠正当前轮次。
  • 深度 / 总时 / 每候选时间：短按调整当前档位，长按切换思考方式。
  • Hash：调整引擎哈希内存。
  • 缩小：把面板收成悬浮球；通知栏同步显示悬浮球状态。单击球恢复面板后，通知文案同步恢复面板状态；拖动球可改变位置。
  • 关闭：关闭整个辅助会话，释放屏幕投影与悬浮窗并关闭本应用无障碍服务；重新准备时会重新建立屏幕识别环境。

状态、箭头与识别

  • 蓝色箭头表示暂定候选，绿色箭头表示建议已经定着。
  • 识别结果会经过连续八个样本画面稳定、模型置信度、棋盘结构和轮次检查；非法棋面会被拒绝并立即请求受控重识别；缺子保护只拦截证据充分的残缺子集，完整的新盘面交给连续帧跟踪确认，不用旧棋面补写当前结果。
  • 落子核对超时期间保留上一张棋面作临时显示，但停止沿用旧建议；首个新稳定画面确认后再替换基线，不会突然显示空棋盘。
  • 暂停、手动模式或一键关闭后，不继续识别和计算。暂停会断开屏幕帧输出并释放帧读取器，但尽量保留授权和无障碍前台监听；因切出触发的临时暂停会在原棋盘回到前台后恢复，手动暂停则仍需用户点“继续”。仅投影被系统结束或Surface重接失败时才重新授权。
  • 缩成悬浮球后若位置异常，程序会把球夹回状态栏与导航栏之间的可见区域。

权限与隐私

  • 屏幕录制仅用于设备本地棋盘识别；悬浮窗用于展示状态和建议。
  • 无障碍服务仅在自动落子时发送点按或拖动手势，不读取控件文字或遍历界面内容。
  • 识别与引擎计算均在设备本地完成，不要求上传棋盘截图。

问题处理

  • 长时间没有识别：确认已在悬浮窗内点击开始、棋盘完整可见，并等待稳定画面。
  • 只显示建议但不落子：检查自动走子、屏幕操作通道、己方颜色和当前轮次。
  • 悬浮球不易看见：回到辅助页调大球体；新版会自动把保存位置夹回屏幕安全区。
  • 不确定 APK 版本：优先使用普通 armv8；支持 ARMv8.2 dotprod 的设备可尝试 dotprod 版。

使用边界

本应用仅供个人学习、技术研究与文化交流。屏幕识别、悬浮窗建议和自动落子均由用户主动启用；使用时请遵守当地法律法规、软件许可和所在平台规则。
