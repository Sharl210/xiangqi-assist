# 象棋辅助 1.3.4 发布说明

## 版本信息

- 应用版本：`1.3.4`
- 版本代码：`8`
- 包名：`com.xiangqi.assist`
- 发行标签：`v1.3.4`
- 兼容变体：ARMv8 与 ARMv8 dotprod

## 本版内容

- 修复静止棋盘画面下 VirtualDisplay 不再投递新帧时，稳定窗口无法放行导致整轮零识别的问题。
- 修复取帧重建后已经收到帧仍被看门狗反复判定为取帧停摆的问题。
- 连续取帧停摆达到上限时改为提示重新授权屏幕共享，避免无限重建。
- Medium 缺少黑将时增加当前帧黑将类别定向复核；复核结果仍必须通过双王、位置、同格冲突和完整棋面安全门。
- 连续识别失败继续按每三次阶梯降阈值，成功后恢复严格基线。
- 保留原始 V5 Medium 主模型与原始 V5 Lite 回退模型。

## 验证边界

- `PipelineHealthPolicyTest` 与 `YoloPipelineTest` 定向测试通过。
- 双变体 Release 构建与 APK v2 签名验证通过。
- 全量 JVM 测试：472 项中 464 项通过；8 项因本机 Robolectric 原生图形库缺失失败。
- Medium 静止棋盘、黑将漏检、自动落子、Lite 真机复测和功耗实测仍需设备验证；本版不把主机测试结果当作真机完成证据。
