# 象棋辅助 1.3.4 发布说明

## 版本信息

- 应用版本：`1.3.4`
- 版本代码：`8`
- 包名：`com.xiangqi.assist`
- 发行标签：`v1.3.4`
- 兼容变体：ARMv8 与 ARMv8 dotprod
- 本次构建：2026-10-01（提交 `e64ee44`）

## 本版内容

### 识别与确认

- 同格类别冲突改为「胜负明确即放行」：分差足够且最终格确实落在胜出候选上时不再整帧否决，
  仍须通过双王齐全、棋面结构、棋子位置三道安全门；分差不明的僵局继续拒绝。
- 识别确认链提速：普通确认由 3 帧改为 2 帧，识别稳定窗口由 4 帧改为 3 帧，
  整屏复核基础间隔由 1.8 秒放宽到 3 秒，类别纯变化确认窗口由 8 帧缩短到 4 帧。
- 随机等待、反作弊间隔、预选落子与正式落子时序均未改动。
- 接上终点棋子类别纠错：棋子被识别成同色另一类别时，用起点原类别还原，
  并经规则引擎验证确为一步合法着法后才采纳。
- 追踪器的候选匹配收紧为只吸收占用格差异，不再把「同一格换了汉字」当同一候选接受。

### 状态机与看门狗

- 取帧与看门狗改为按「引擎是否真的在搜索」区分：兜底的计算中状态不再关闭取帧，
  看门狗也不会因此停止续期（此前会造成长时间完全静默）。
- 兜底「计算中」干等超时后作废该局面的分析周期并重新发起，限速且最多重试 3 次，
  用尽即放弃该棋面回到重新识别。
- 送引擎前的自检失败（例如识别结果导致非走子方被将军）会作废整份棋面与轮次，
  退回重新识别，而不是反复重试同一份错误输入。

### 取帧与稳定窗口

- 稳定的静止画面不再永久停止识别：画面无变化或持续抖动时也会按节流间隔放行一次，
  避免被看门狗误判成取帧故障而反复丢弃已经对好的棋盘网格。

## 验证边界

- 定向单元测试全部通过；全量 JVM 测试 505 项中 8 项因本机 Robolectric 图形原生库缺失失败，无逻辑失败。
- 双变体 Release 构建与 APK 签名验证通过，证书指纹与本项目正式签名一致。
- 真机复测的项目（动画期间不提前计算、各类棋面持续识别、功耗实测）仍需设备验证；
  本版不把主机测试结果当作真机完成证据。

## 校验

- 下载后可用 `SHA256SUMS.txt` 校验两个 APK 的完整性。
- 安装前请先卸载同包名的其他签名版本，避免签名不一致导致安装失败。
