# 移动端识别模型档位评估

**项目**：XQDK 象棋辅助
**适用版本**：1.3.3（versionCode 7，待发布）
**目标**：效果优先；用户界面只提供 `Lite / Low / Medium / High` 四个效果语义档位；单个模型文件不超过 `200,000,000 bytes`；原始 V5 Lite 固定作为最终兼容保底。

## 当前结论

- `High` 是当前效果优先档，但其 APK 工件是历史 `Medium+universal/旋转鲁棒` 复合资源，不是独立训练的原生大型权重；文案和日志必须明确这一边界。
- `Medium` 是原生 YOLO26-S 中国象棋15类候选，已转换为 Android TFLite 并接入独立 raw 输出适配器；同格类别竞争、逐格效果和目标设备效果仍在验证，不能仅凭能运行宣称全面优于旧路线。
- `Low` 是此前稳定的原始 V5 Medium，作为 Medium 运行时兼容性失败后的内部回退。
- `Lite` 是原始 V5 Lite，作为最终最小兼容保底，不被未验证的新模型替换。
- 用户选择动作只写入配置，不创建或展开悬浮窗，不热切换当前会话；下一次一键准备或点击开始/继续时才执行兼容性探测。实际探测顺序为 `High → Medium → Low → Lite`，只因资产、Interpreter、张量、契约或受控推理失败回退；负载、温度、功耗和速度只作提示。
- 原生体量更大的中国象棋专用现成权重仍未取得。没有来源、类别契约、Android部署和固定帧集效果跃迁证据时，不新增“更大”用户选项，也不把复合模型冒充原生大模型。

## 原生 YOLO26-S 候选取证

### 来源与训练类别

- 来源：公开仓库 `DuyLeTran/DeepXiangQi` 的 `Reconstruction/weights/detect-ultra.pt`。
- `data_detect.yaml` 声明15类：14种红黑棋子和 `board`。
- 原始权重大小：`20,376,645 bytes`；公开训练来源只能证明候选可进入验证，不能替代逐格标注、许可证复核和真机验收。

### Android 工件与输出适配

- 输入：`[1,640,640,3] FLOAT32`、NHWC RGB。
- 输出：`[1,19,8400] FLOAT32`，4个框参数加15个类别分数，没有 YOLOv5 objectness 列。
- `YoloModelFormat.YOLO26_RAW` 和 `Yolo26Postprocessor` 使用独立解码路径，不把新模型套进旧 `[1,25200,20]` 解码器。
- 运行时会检查资产大小、输入/输出形状、数据类型、Interpreter 分配和一次零输入受控推理。
- 同一棋格出现不同类别候选时保留诊断信息并走安全拒绝，不按最高分强行猜测。

### 主机和样本边界

- ONNX 与 TFLite 同输入主机复核最大绝对差约 `0.001313`，相关系数约 `1.0`。
- 当前异常截图主机单线程热身后推理约 `200–230ms`；这不是 Android 手机 P50/P95，也不是功耗或温升实测。
- 当前样本仍出现同格不同类别竞争；没有完整逐格人工标注时，检测数量、置信度、模型名称和参数量都不能证明准确率提升。

## High 复合资源边界

`yolov5l_xq_fp32.tflite` 是既有 Medium 与 universal/旋转鲁棒模型的逐检测行集成，输入输出契约仍为 `[1,640,640,3] → [1,25200,20]`。它可以作为当前 High 的历史可用资源，但不是独立训练的 YOLOv5-L，也不是原生大型权重；不能用它证明原生大型目标已经完成。

## 已排除的替换方式

- 通用 COCO 权重：没有当前红黑棋子类别训练时不能直接替换。
- 64×64单格分类、7类基础棋种检测、单类 occupancy 模型：不满足当前整棋盘15类检测契约。
- 无法取得权重、许可证或 Android 契约的网页模型：只保留为取证线索，不打入 APK。
- 与现有模型随机输入逐元素等价的归档工件：不能作为效果升级证据。
- 从零训练：当前没有数据集、训练设备和时间预算，路线禁止从零训练；只允许转换或适配已有成品权重。

## 替换验收门

候选模型只有同时满足以下条件，才允许替换当前档位：

1. 权重来源、许可证、训练类别和输入输出契约可追溯；
2. 文件实际字节数不超过 `200,000,000`；
3. 主机 ONNX/TFLite/LiteRT 数值和后处理可重放；
4. Android Interpreter 或 LiteRT 能真实创建、分配张量并完成受控推理；
5. 使用相同输入、裁剪、预处理、线程数和连续稳定帧门比较；
6. 用户异常样本逐格类别、颜色、位置、方向和 FEN 不劣化，并产生可观察效果跃迁；
7. 双王、非法棋面、低置信类别、同格冲突和自动落子前归属安全门继续有效；
8. 真机补测冷启动、P50/P95/P99、PSS/native heap、温升、功耗、降频和长时间稳定性；
9. 失败时能够回滚到已知可用档位和原始 V5 Lite。
